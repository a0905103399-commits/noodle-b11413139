## 專案緣起與情境故事 (Scenario Story)

深夜在研究室熬夜奮鬥時，泡麵在微波爐加熱或悶泡的關鍵幾分鐘內，經常面臨被路過室友順手牽羊的風險。本系統將微波爐打造成具備多重防禦的「智慧保險箱」，透過嚴密的狀態機控制、實體托盤感測、防劫開關與序列埠密碼驗證，徹底守護研究生的宵夜安全。

## 有限狀態機 (FSM) 與防盜邏輯架構

系統狀態機嚴密維護四大情境，杜絕一切偷吃可能：

```text
                  +-------------------------------------------------------+
                  |                     開機初始化                         |
                  +-------------------------------------------------------+
                                              |
                                              v
      +-------------------------------------------------------------------------------+
      |                                STATE_IDLE (待機模式)                           |
      | - 綠燈 PA5：非阻塞呼吸燈 (軟體 PWM)                                              |
      | - 紅燈 PB0：滅 / 蜂鳴器 PB1：靜音                                              |
      | - PA1 托盤感測：允許為空 (拔開不報警)                                          |
      +-------------------------------------------------------------------------------+
           |                                                      ^
           | 指令 'LOCK <密碼>'                                     | [取餐完畢]
           | 且 PA1 == 0 (泡麵已在位接地)                            | 拔開 PA1 感測線
           v                                                      | (泡麵安全取出)
      +-----------------------------------------+                 |
      |        STATE_ARMED (守護上鎖模式)        |                 |
      | - 綠燈 PA5：每 250ms 規律閃爍            |                 |
      | - 紅燈 PB0：滅 / 蜂鳴器 PB1：靜音       |                 |
      +-----------------------------------------+                 |
        |                  |                    |                 |
        | 密碼比對正確      | 密碼連續輸錯 3 次   | 未授權拔除 PA1   |
        | (strcmp == 0)    | (failed >= 3)      | 或 按下 PC13開門 |
        v                  |                    |                 |
+----------------------+   |                    |                 |
| STATE_UNLOCKED(解鎖) |   |                    |                 |
| - 綠燈 PA5：恆亮      |   |                    |                 |
| - 紅燈 PB0：滅        |   |                    |                 |
+----------------------+   |                    |                 |
        |                  |                    |                 |
        | (拔開 PA1 取餐)   v                    v                 |
        +----------------> +--------------------------------------+
                           |          STATE_ALARM (警報模式)        |
                           | - 綠燈 PA5：滅                       |
                           | - 紅燈 PB0：恆亮                      |
                           | - 蜂鳴器 PB1：急促方波狂鳴             |
                           +--------------------------------------+
                                              |
                                              | 輸入指令 'RESET'
                                              | 且 必須確認 PA1 已插回接地
                                              v
                                      (回到 STATE_IDLE)

```

1. **STATE_IDLE (待機模式)**：綠燈 PA5 呼吸調光，微波爐處於非鎖定狀態，此時微波爐允許為空（PA1 拔開不誤報警）。
2. **STATE_ARMED (守護上鎖模式)**：需在泡麵在位（PA1 接地）時輸入 `LOCK <密碼>` 進入。綠燈每 250ms 閃爍。任何未授權開門（PC13）或拔走托盤（PA1 拔開）立即觸發警報；密碼輸錯達 3 次亦強制警報。
3. **STATE_UNLOCKED (授權解鎖模式)**：密碼輸入正確後解鎖，綠燈轉為恆亮。此狀態為合法取餐狀態，拔除 PA1 會發出歡迎短嗶並回到待機。
4. **STATE_ALARM (警報狂鳴模式)**：紅燈恆亮、蜂鳴器以 300ms 週期（150ms 鳴叫 / 150ms 靜音）連續狂鳴。**防盜邊界鎖定：解除警報必須先將 PA1 感測線插回接地，才能輸入 `RESET` 復原系統**。

## CLI 命令列互動清單 (Command-Line Interface)

透過 PuTTY 或終端機軟體連接（115200 8N1）：

* `STATUS`：查詢系統目前狀態、PA1 感測線電位狀態與密碼錯誤次數。
* `LOCK <密碼>`：在待機狀態下設定密碼並啟動守護（預設密碼為 `12345`）。
* `<純密碼>`：在守護狀態下輸入密碼解鎖微波爐門。
* `RESET`：在警報狀態下解除警報（強制檢查 PA1 必須插回接地）。
* 支援退格鍵（Backspace, `\b` 或 ASCII 127）與鍵盤即時輸入回顯。

## 程式碼架構與關鍵技術對照 (Key Features Checklist)

* **純暫存器控制 (Direct Register Access)**：
* GPIO 控制全面採用 `BSRR`（Bit Set/Reset Register）進行無干擾原子位元寫入，取代高開銷之 HAL 函式。


* 序列埠發送直接輪詢 `USART2->ISR` 之 `TXE` 旗標並寫入 `USART2->TDR`。




* **序列埠中斷與環形緩衝區 (UART RXNE Interrupt & Ring Buffer)**：
* 啟用 `USART2->CR1 |= USART_CR1_RXNEIE_RXFNEIE`。


* 中斷服務常式接收字元並推進 64-byte `rx_ring_buffer`，搭配 Overrun Error (`ORECF`) 自動清除機制，主迴圈零掉字。




* **非阻塞計時架構 (Non-blocking Timing Architecture)**：
* 全系統除硬體微秒方波外，禁止使用卡死 CPU 的 `HAL_Delay()`。


* 透過 `HAL_GetTick()` 計算時間差維護綠燈呼吸 PWM（15ms/階）、守護閃爍（250ms）與警報間歇音效（300ms 週期）。




* **EXTI 外部中斷 (External Interrupt)**：
* PC13 藍色按鍵配置為下降緣觸發，中斷回呼函式僅標記旗標 `exti13_flag = true`，耗時邏輯全數移交主迴圈處理，符合嵌入式最佳實踐。

## 可量測驗收條件 (Acceptance Criteria)

依照課程規範，本專案提供具體可量測、判得出對錯的驗收條件：

1. **守護防盜測試**：在 `ARMED` 模式下拔開 PA1 杜邦線，0.1 秒內終端機印出 `[警報啟動]`，PB0 紅燈點亮，PB1 蜂鳴器以 150ms 鳴叫 / 150ms 靜音急促響起。


2. **防暴力破解測試**：連續輸入錯誤密碼 3 次，系統在第 3 次驗證失敗後 0.5 秒內強制進入 `ALARM` 狀態，終端機顯示錯誤次數並警報。


3. **強制歸位復原測試**：在 `ALARM` 狀態下未插回 PA1 即輸入 `RESET`，系統印出 `[拒絕解除]` 並維持警報；將 PA1 插回 GND 後輸入 `RESET`，0.2 秒內紅燈熄滅、蜂鳴器靜音並返回 `IDLE` 綠燈呼吸。


4. **合法取餐測試**：輸入正確密碼切至 `UNLOCKED`，綠燈轉為恆亮；此時拔開 PA1 取餐，系統發出 600ms 取餐長音並自動平順回到 `IDLE`。

## AI 協作使用揭露 (AI Assistance Disclosure)

依修課規範誠實揭露 AI 輔助開發歷程：

* **輔助範圍**：有限狀態機（FSM）骨架規劃、CMSIS 暫存器操作語法除錯（如 `USART2->TDR`、`GPIOA->BSRR`）、軟體 PWM 呼吸燈時序演算法輔助。


* **人工查核與修正**：
* 自行修正 PA1 待機模式拔除誤報警之邊界條件邏輯。


* 驗算 PB1 蜂鳴器之延遲迴圈參數，確保方波頻率維持在 2.5 kHz 最佳共振點。


* 全面查核 RM0440 參考手冊，確認暫存器名稱與 STM32G474RETx 規格完全相符。
